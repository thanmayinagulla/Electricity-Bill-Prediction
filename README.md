# ⚡ Electricity Bill Prediction using Machine Learning

A Machine Learning-based project that predicts electricity bills based on relevant electricity consumption and household-related features.

## 🚀 Features

- 📊 Data preprocessing and cleaning
- 🔍 Exploratory Data Analysis
- 🤖 Multiple Machine Learning models
- 📈 Model performance comparison
- ⚡ Electricity bill prediction
- 📉 Regression evaluation using MAE, MSE, RMSE and R²

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Machine Learning

## 🤖 Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Extra Trees Regressor
- XGBoost Regressor

## 📊 Model Performance

| Model | MAE | RMSE | R² Score |
|---|---:|---:|---:|
| Extra Trees | 29.71 | 63.82 | 0.5930 |
| Random Forest | 32.90 | 68.42 | 0.5322 |
| XGBoost | 36.33 | 71.45 | 0.4899 |
| Decision Tree | 38.87 | 90.60 | 0.1798 |
| Linear Regression | 52.55 | 91.17 | 0.1693 |

🏆 **Best Performing Model: Extra Trees Regressor**

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Electricity Bill Prediction

## 🎯 Objective

To develop a machine learning model capable of estimating electricity bills from relevant input features and compare different regression algorithms to identify the best-performing model.
